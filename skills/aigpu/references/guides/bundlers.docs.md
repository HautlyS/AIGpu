# Using AIGpu with Vite and other bundlers

`effect(gpu, source)` accepts WGSL as a string, so a bundler is optional. Use a loader when shaders live in `.wgsl` files and import other WGSL modules. The loader resolves the graph at build time and hands AIGpu one finished shader.

## Install

```sh
pnpm add aigpu @aigpu/wgsl @aigpu/wgsl-std
```

All packages are published under the MIT license and can also be consumed from a local workspace or a private registry. No hosted service or API key is required.

## Vite

```ts
// vite.config.ts
import { defineConfig } from "vite";
import { wgslVitePlugin } from "@aigpu/wgsl/loader-vite";

export default defineConfig({ plugins: [wgslVitePlugin()] });
```

Add one ambient declaration for TypeScript:

```ts
// src/wgsl-env.d.ts
declare module "*.wgsl" {
  const source: import("aigpu").ShaderSource;
  export default source;
}
```

Then import a shader like any other module:

```ts
import { effect } from "aigpu";
import shader from "./agent.wgsl";

const visual = effect(gpu, shader, { label: "agent" });
```

## Webpack-compatible loaders

```js
// webpack.config.mjs
import wgslWebpackLoader from "@aigpu/wgsl/loader-webpack";

export default {
  module: {
    rules: [{ test: /\\.wgsl$/u, use: [{ loader: wgslWebpackLoader }] }],
  },
};
```

The adapter is a small open-source loader and does not contact a registry or service while building. For a plain Node script, skip the loader and use `resolveShader()`; see [Using AIGpu without a bundler](bundlers.docs.md).

## Browser component lifecycle

A browser integration should create the GPU context and render loop after the canvas is mounted, and stop the loop plus dispose the context when the component is removed. This applies equally to React, Svelte, Vue, or a hand-written DOM application:

```ts
import { agentAnimation, clock, frameLoop, init, surface } from "aigpu";

export async function mountAgent(canvas: HTMLCanvasElement) {
  const gpu = await init();
  const output = surface(gpu, canvas);
  const time = clock(gpu);
  const animation = agentAnimation(gpu, { initial: { status: "thinking" } });
  const loop = frameLoop(gpu, (frame) => {
    animation.tick(time.time);
    frame.pass(output, animation.effect);
  });
  return () => { loop.stop(); gpu.dispose(); };
}
```

## Validate WGSL before shipping

Bundler loaders parse imports and produce a source object, but they do not need a real adapter during every development build. Run the independent checker in CI or pre-commit when device-backed validation is required:

```sh
npx aigpu check src/agent.wgsl --require-validation
```
