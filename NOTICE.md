# AIGpu

AIGpu is an independent, offline-first project built on open standards and open-source packages: WebGPU, WGSL, TypeScript, Vite/Webpack loaders, Dawn bindings, Vitest, and the Model Context Protocol server.

No vendor account, deployment, analytics, blob storage, hosted examples catalog, proprietary SDK, or hosted control plane is required to build, test, or run AIGpu.
