# AIGpu provenance

AIGpu is an independent, offline-first fork of the MIT-licensed `vgpu` codebase. The original copyright notice is preserved as required by the MIT license; all fork changes are attributed to AIGpu contributors.

The fork deliberately removes hosted applications and integrations from the runtime and development workspace. The maintained stack is based on open standards and open-source packages: WebGPU, WGSL, TypeScript, Vite/Webpack loaders, Dawn bindings, Vitest, and the Model Context Protocol server.

No vendor account, deployment, analytics, blob storage, hosted examples catalog, proprietary SDK, or hosted control plane is required to build, test, or run AIGpu.
